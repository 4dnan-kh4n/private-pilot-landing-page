PRIVATEPILOT - LOCAL WEBPAGE PRIVACY

INSTALLATION
1. Extract this ZIP.
2. Open chrome://extensions in Chrome or a compatible Chromium browser.
3. Enable Developer mode and choose Load unpacked.
4. Select privatepilot-extension, the extracted folder containing manifest.json.
5. Open a normal HTTP or HTTPS webpage and click the PrivatePilot toolbar button.
6. Grant access to this site when Chrome asks.
7. Choose Review local analysis to see the detected private details.
8. Use Unmark to restore a detail on the page, or Mark private to hide it again.

UPDATING
Reload PrivatePilot in chrome://extensions, reload the webpage, and close/reopen
the side panel. Old page scripts do not update until the webpage reloads.

LOCAL PROCESSING
No assistant service, backend or AI key is needed. PrivatePilot checks page
text and replaces detected values locally. No page text or mappings are uploaded.
The review refreshes when the page, tab or detected content changes.
Passwords and OTP controls are never read and cannot be unmarked.
Sign-in identity inputs keep their original values so login forms work.

LIMITS
Detection can miss details or make mistakes. Check the page after scanning.
Another site needs its own permission. Browser-protected pages and frames
without permission remain inaccessible.
PrivatePilot does not intercept or control other browser assistants.
Chrome does not guarantee it runs before another browser agent reads the page.
Use fictional data for demonstrations.
